### Список використаних сервісів

У цій роботі ми використовували такі хмарні інструменти:

1.  **Google Drive (Docs, Sheets, Slides):** Для спільного зберігання файлів, написання звіту, аналізу сервісів та створення презентації.
2.  **Google Colab:** Для аналізу даних за допомогою Python та Pandas.
3.  **Replit:** Для спільної розробки простого Python-калькулятора.
4.  **Canva:** (Якщо використовували) Для дизайну презентації.
5.  **GitHub:** Для фінального зберігання коду та публікації опису проєкту через GitHub Pages.
